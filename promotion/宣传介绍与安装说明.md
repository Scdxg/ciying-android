# 词映 Ciying

词映是一款 Android 离线拼音输入法，在中文候选词右侧显示英文释义。输入中文时，可以顺便了解对应英文；例如输入 gongshi，可看到“公式 / formula”和“公示 / public notice”。

支持全拼、声母简拼、拼音前缀补全与连续拼音组句，结合前文和本机选词习惯调整候选顺序，并提供漏字母、多字母、相邻键误按及相邻字母颠倒的单次拼写纠错。日常输入支持英文、数字、标点、退格、横屏及编辑器动作。

内置 265,799 条词音记录，其中 205,926 条附英文释义。无需账号，输入处理在本机完成；应用没有联网权限，选词偏好仅保存在本机。界面采用森林配色。

当前为 0.3.2 测试版，适用于 Android 8.0 及以上，暂不支持 iPhone。部分词条暂无英文释义，释义未逐条人工校对，仅供参考；复杂句子仍可能需要手动选词。本版没有双拼、自造词及模糊音设置。

## 安装方法

1. 用手机浏览器从可信下载链接获取 APK。
2. 打开 APK，按系统提示允许该浏览器或文件管理器安装应用，再确认安装。
3. 打开词映，按照页面引导启用词映输入法。
4. 切换当前输入法为词映，即可输入。

无需开启 USB 调试。手机厂商的安装提示和入口可能不同。若聊天应用不能直接下载，请在浏览器中打开下载页。

卸载：在系统设置的应用列表中找到“词映”，选择卸载；也可尝试长按应用图标进入卸载入口。
