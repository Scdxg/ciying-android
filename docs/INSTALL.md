# 安装与兼容性

## 下载安装

打开 https://github.com/Scdxg/ciying-android/releases/tag/v0.3.2-beta ，展开 Assets，下载 Ciying-0.3.2-beta.apk。Source code 是源码压缩包，不是安装包。

下载后在浏览器的下载列表或文件管理器里打开 APK，按系统提示确认安装。若聊天应用不能直接下载，可用浏览器打开链接。普通用户不需要 USB 调试。

打开词映，按首页按钮启用输入法并切换到词映。不同厂商的设置名称和安装确认可能不同。

## 兼容性范围

- 最低 Android 8.0；iPhone 不支持。最低版本是安装条件，不代表所有满足条件的机型均已验证。
- 已验证：Redmi K50 Pro，包含输入、横屏、WebView 和多种输入框检查。
- 未验证：vivo、OPPO、三星、荣耀及其他机型和系统版本，不能宣称已全面适配。
- 词映使用标准 Android 输入法接口，没有依赖小米专用接口。预计可在其他兼容 Android 手机上运行，实际仍需真机测试。
- 不同系统可能对外部来源安装做额外检查。安装失败不一定是输入引擎不兼容，应保留具体提示用于排查。
- 密码框可能由厂商安全键盘接管，这是系统行为。
- 屏幕尺寸、字体缩放、手势导航和不同 App 的输入框可能影响键盘布局、候选显示及编辑器动作。
- 目前是调试签名测试包。以后换为正式签名时通常需要先卸载测试版，卸载会清除本机选词偏好。

## 建议先做的短测试

保留原输入法以便切换。在词映自带试打框和常用 App 中检查：输入 gongshi、选择“公式”、删除文字、连续拼音、英文数字标点、横屏和返回键收起。再检查键盘底部是否被导航栏遮挡。

遇到问题请提供手机型号、Android/系统版本、词映版本、出问题的 App 名称和复现步骤。截图请避开聊天内容、密码等个人信息。

## 卸载

先切换到其他输入法，再在系统设置的应用列表中找到“词映”并卸载。
